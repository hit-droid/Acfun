=====================================================================
深度卷积（DW）/ 分组卷积（Grouped）：本轮新增，对标 MNN 轻量网络算子
=====================================================================
- 深度卷积（acfun_conv2d_dw）：groups==Cin==Cout，每个输出通道仅与其同名输入通道做 KH×KW 点积，
  权重布局 [C,KH,KW]。此前若当普通卷积走 im2col+GEMM（K=KH·KW 极小，算术强度崩溃）无法正确表达，
  且效率极低。现以 AVX-512 跨通道 16 路向量化（src/dw_avx512.cpp）替代逐通道标量点积：
  - 权重预转置 wT[K·16] 驻留 L1，每输出像素对 KH·KW 个空间偏移各做 16 路 _mm512_fmadd_ps；
  - 尾通道 / padding 以 AVX-512 掩码 load/store 归零，消除边界分支。
- 分组卷积（acfun_conv2d_g）：通用 groups 组，权重 [groups,Cout_per,KH·KW·Cin_per] 组间连续；
  groups==Cin==Cout 自动路由深度卷积（零额外开销），否则各组提取连续缓冲后复用既有
  1x1 / Winograd / im2col 子路径（NHWC 各组通道交错，需先聚合）。
- 模型 type 7（ConvGrouped）：acfun_model_infer 在 groups>1 改调 acfun_conv2d_g，BN 折叠组感知
  （除以 groups 修正权重计数），从而深度可分离 / 分组网络可正确表达与融合。
- 实测（沙箱 AVX-512）：深度卷积较朴素标量参考 5.9~35.4x（max|Δ|<1e-6）；分组卷积 1.7~32.3x
  （max|Δ|<4e-6）。32 组纯深度卷积达 32.3x，低频组（g4/g8）受每组建模开销约 2~4x。

=====================================================================
INT8 量化推理（AVX-512 VNNI，vpdpbusd，对标 MNN int8 路径）
=====================================================================
后端: AVX512-VNNI (Zen5)
量化: 对称逐通道权重 scale + 带零点(zp=128)逐张量激活; 零点偏置校正并入 bias。

> INT8 GEMM 微内核: 扩展 4×4 面板布局 + K 展开(UU) + 列展开(UC) + B 列块驻留寄存器跨 GB 个
> 4 行块复用(把每 dpbusd 的负载比从 2 降到 ~0.5), 突破 2 个 load 端口对带内存 dpbusd 的钳制
> (~60-80 GOPS) 抬升到 ~90 GOPS。正确性: 跨 60 组尺寸(含非整除边界) max|Δ|=0。

=====================================================================
Winograd F(4,3) 大瓦片 + 输出变换 512-bit 向量化（已含于本轮）
=====================================================================
- 算法：3x3 / stride1 / pad1 专用快速卷积的更大瓦片版本。每 4x4 输出块（依赖 6x6 输入块 +
  3x3 权）乘法量从 9·Cin·Cout·16 降到 36·Cin·Cout，每输出乘法量降至 F(2,3) 的 ~0.56×
  （理论乘法再减 1.78x），且瓦片数降为 F(2,3) 的 1/4，摊薄每瓦片变换开销与 g_hat 重取。
- 实现：src/winograd43.cpp（标量 + dispatcher）+ src/winograd43_avx512.cpp（-mavx512f -mfma）；
  输出变换 Y=AT·M·ATᵀ 改为 16 个输出空间位置各持一条 c 块累加器、对 36 个变换域元素做 scatter-add
